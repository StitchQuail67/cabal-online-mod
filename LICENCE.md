## 🧩 About

**Cabal Online Mod** is a comprehensive overlay menu for Cabal Online featuring player and mob ESP, a minimap radar, loot tracker, skill cooldown HUD, auto-skill rotation, and per-character config profiles.

Based on popular community mods for the Cabal Online client.

---

## ✨ Features

### 🎮 Core Mods
- Player ESP — box and name overlays for nearby players
- Mob ESP — highlight monsters, bosses, and world spawns
- Radar — minimap overlay showing entities around the player
- Loot Tracker — log drops, rarity, and dungeon chest contents
- Cooldown HUD — live skill and potion timers on screen

### 🎨 Interface & Unlocks
- Overlay Menu — in-game GUI with draggable panels
- Config Profiles — save and load settings per character
- Keybind Manager — rebind every mod toggle
- Crosshair Helper — center-screen aim guide for ranged classes

### 🏋️ Utility & Training
- Auto-Skill — configurable rotation with delay control
- Auto-Pot — trigger HP and MP potions at set thresholds
- Waypoint Marker — pin dungeon routes and farming spots
- Damage Meter — track party DPS during runs
